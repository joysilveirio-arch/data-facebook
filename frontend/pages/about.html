📊 Sentimen Facebook

Tentang Sistem

Platform Analisis Sentimen Media Sosial Facebook

Informasi Aplikasi

Aplikasi ini digunakan untuk mengelola, memproses, menganalisis, dan memprediksi sentimen teks dari data Facebook.

Sistem dirancang untuk mendukung teks multibahasa, termasuk Tetum, Bahasa Indonesia, Portugis, dan Inggris, sesuai kemampuan preprocessing dan model yang digunakan.

Teknologi yang Digunakan

  • Backend: Python dan FastAPI
  • Database: SQLite
  • Machine Learning: scikit-learn
  • Text Processing: preprocessing dan TF-IDF
  • Frontend: HTML, CSS, dan JavaScript

Fitur Utama

  • Manajemen dan eksplorasi dataset.
  • Preprocessing dan pembersihan teks.
  • Pelabelan sentimen secara manual.
  • Pelatihan model machine learning.
  • Prediksi sentimen otomatis.
  • Dashboard analitik dan visualisasi.
  • Statistik label dan distribusi prediksi.
